# Простой сайт-визитка

Это простой одностраничный веб-сайт, созданный на HTML и CSS. Он представляет собой личную визитку Александра, где он рассказывает о себе и предлагает связаться.

## Что в проекте

- **index.html**: Основной файл с содержимым страницы (текст, ссылки, структура).
- **style.css**: Файл стилей, который делает сайт красивым (цвета, шрифты, расположение).

## Как запустить

1. Скачай или склонируй этот проект на свой компьютер.
2. Открой файл `index.html` в любом браузере (двойной клик или перетащи файл в браузер).
3. Готово! Сайт откроется и будет работать без интернета.

## Для разработчиков

Если хочешь изменить сайт:
- Редактируй `index.html` для изменения текста или структуры.
- Редактируй `style.css` для изменения внешнего вида.
- Открывай файлы в редакторе кода (например, VS Code) и сразу проверяй в браузере.
